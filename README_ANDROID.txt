CastVector v5.4.1 — Community Live Sign-In Hotfix

This fixes the Community Live screen showing “Sign in” even when the main CastVector account is already signed in.

Android/GitHub update:
1. Upload index.html and chat.js from this folder to the ROOT of your existing CastVector GitHub repository.
2. Replace the existing files.
3. Commit to main.
4. Wait for GitHub Pages to update.
5. Completely close CastVector and reopen it.
6. Open Community Live.

Do NOT change coastcast-config.js.
Do NOT rerun the Community SQL if it already ran successfully.
Do NOT recreate your account or Premium access.
