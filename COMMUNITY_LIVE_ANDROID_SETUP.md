# CastVector v5.4 Community Live — Android setup

1. Upload the v5.4 files to the same GitHub repository and replace matching files.
2. Keep your existing `coastcast-config.js`; this update intentionally does not include or replace your live Supabase config.
3. In Supabase open **SQL Editor → New query**.
4. Open `CASTVECTOR_COMMUNITY_LIVE_SETUP_ANDROID.txt` on your phone, Select all, Copy, Paste into Supabase, and Run.
5. Reopen CastVector and sign in.
6. Open **Trips → Community** or the Community button, choose a public chat name, and send a test message.
7. Have the complimentary/family test account open Community Live on another phone to verify realtime chat and the online count.

If Community Live says the backend is not activated, the SQL script has not been run in the same Supabase project used by the app.
