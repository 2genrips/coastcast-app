# CastVector Community Live — v5.5

If Community Live v5.4 is already working, run only:
`CASTVECTOR_COMMUNITY_V5.5_UPGRADE_ANDROID.txt`

`CASTVECTOR_COMMUNITY_LIVE_SETUP_ANDROID.txt`

Then upload the v5.5 app files to the existing GitHub Pages repository. Keep the existing `coastcast-config.js`.
