- Public app name changed to **CastVector Fishing Forecast**.
- Existing compass/fish/wave visual identity and **Plan Smarter. Fish Better.** tagline retained.
- PWA name, metadata, legal/support pages, store drafts, native wrapper, alerts, Community, Premium UI, Owner Console, Family Crew, exports, and share text updated to CastVector.
- Android/PWA icon filenames bumped to v5.3 to help refresh cached installed branding.
- Future package ID set to `com.castvector.fishing`.
- Future Premium product ID set to `castvector_premium_monthly` in the example configuration.
- Existing `coastcast_*` Supabase/database identifiers intentionally retained for migration compatibility.
- Existing live `coastcast-config.js` is intentionally not included so the user's working Supabase credentials are not overwritten.
