# CoastCast v0.9 — Species Intelligence + Regulations + Smart Trip Planner

## New
- Nationwide live-condition species ranking for the current coast.
- Species scores are calculated independently so Red Drum, Striped Bass, Surfperch, Snook, etc. can rank differently under the same forecast.
- Species scoring now uses closeness to each species’ preferred water-temperature and surf ranges instead of letting most favorable forecasts saturate at the same score.
- Personal catch-history signal can add a small score boost when current wind/surf/water conditions resemble successful catches you logged.
- Bait and habitat suggestions for each supported species.
- Regulations Watch detects the U.S. coastal state and opens the official state fishing-regulation source.
- Nationwide fishing-license information shortcut.
- Smart Trip Planner now ranks each day for the species selected in the planner, not only the active Home species.
- Trip priority options: best bite, calmer surf, lower rain, or dawn session.
- Trip plan output includes bait prep, nearby bait stop when available, best fishing window, peak hour, and a regulation reminder.
- Saved trip plan history is kept locally for future trip/calendar work.

## Safety / accuracy
CoastCast does not hard-code legal harvest limits in this build because size, bag, season, gear, protected-area, emergency and federal-water rules can change. Regulations Watch links to the official state source so anglers can verify the current rule before fishing or harvesting.
