# CoastCast v0.5 — Professional + Live Data

## Professional brand upgrade
- Refined compass / fish / wave / location-point brand mark based on the approved CoastCast brand board
- Premium condensed headline typography and Inter UI typography
- Cleaner navy, ocean blue, aqua, seafoam, sky and sand palette
- Professional icon buttons, score ring, navigation, forecast cards, map treatments and footer
- Fishing location names can now wrap to two lines instead of being cut off on smaller Android screens
- Cleaner species selector and tighter mobile spacing

## Live forecast engine upgrades
- Weather: temperature, feels-like, rain, wind, gusts, pressure, humidity, cloud cover, visibility and UV
- Marine: wave height/direction/period, swell height/direction/period, sea-surface temperature and ocean-current fields when available
- NOAA CO-OPS tide predictions from the nearest tide-prediction station
- Nearby bait/tackle lookup with live/fallback status
- New source-status chips tell you which parts are live vs fallback/demo
- Trip packing logic now reacts to UV and low visibility as well as rain, wind, surf and temperature

## Existing features retained
- Species Mode and 0–100 fishing score
- Best fishing window and 7-day trip ranking
- Interactive fishing map, waypoints and bait/tackle directions
- Catch logbook, privacy controls and community prototype
- PWA install support and saved-data migration from v0.4
