# CoastCast 4.0 — Free vs Premium product direction

## Free
- Quick Answer
- Core current conditions
- Basic daily forecast
- Basic map/location access
- Starter catch logbook
- Enough information to understand and trust CoastCast

## Premium — $4.99/month
- Full hourly / 7-day forecast intelligence
- Ocean Network observed-vs-forecast verification
- Species Intelligence and 12-month Seasonal Intelligence
- Bait & Rig Intelligence
- Personal Catch Intelligence / pattern learning
- Scout and Spot Compare
- Coast Watch and 7-Day Trip Calendar
- Command Center and Mission Control
- Smart Alerts
- Smart Departure
- Offline Trip Packs
- Smart Tackle / gear planning
- Advanced analytics and premium community tools

## Premium entitlement sources
All of these resolve to the same active Premium experience:
- Paid subscription
- Family Premium
- Complimentary Premium
- Lifetime Premium
- Promotional Premium

Production entitlement checks must be server verified.
