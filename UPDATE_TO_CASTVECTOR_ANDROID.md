# Update to CastVector v5.3 from your phone

1. Download and extract the CastVector v5.3 ZIP.
2. Upload everything **inside** the `castvector_v5.3_launch_brand` folder to the root of your existing GitHub repository.
3. Replace matching files and commit to `main`.
4. **Do not delete your existing `coastcast-config.js`.** This package intentionally does not include the live config file, so your working Supabase URL/key stay connected.
5. Wait for GitHub Pages, fully close the installed app, and reopen it.
6. If Android still shows the old installed-app name/icon, remove the PWA shortcut/app and install it again after the site updates.

Your existing Supabase account, Owner role, Lifetime Premium, Complimentary Premium users, Family records, catches, trips, and cloud data remain compatible.
