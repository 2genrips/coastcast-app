# Content-rating notes

CastVector includes user-generated Community Live chat.

When completing the content-rating questionnaire:
- disclose user-generated content / user interaction when asked
- disclose that users can communicate with other users
- note that report, block and moderation controls are provided
- do not mark the app as a child-directed product
- answer every questionnaire from the final production behavior

Community Live should retain:
- report message
- block user
- mute/ban moderation
- owner report queue
- community rules
