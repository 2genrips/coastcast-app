# Update CastVector to v5.6 from Android

1. Extract `castvector_v5.6_launch_candidate.zip`.
2. Upload everything inside `castvector_v5.6_launch_candidate` to the root of your existing CastVector GitHub repository.
3. Replace matching files.
4. **Do not delete or replace your existing `coastcast-config.js`.** This package intentionally does not contain that live file.
5. Commit to `main`.
6. Wait for GitHub Pages to update, fully close CastVector, and reopen it.
7. Confirm version 5.6.
8. Confirm Owner/Lifetime Premium and Community Live still work.
9. The new purchase buttons only launch Google Play checkout in the native Android build.
