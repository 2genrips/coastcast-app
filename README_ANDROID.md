# CoastCast v1.4 — Android / GitHub Pages Update

1. Download `coastcast_v1.4_bait_gear_beta.zip`.
2. Extract it with **My Files** on Android.
3. Open the extracted `coastcast_v1.4` folder.
4. In the existing CoastCast GitHub repository choose **Add file → Upload files**.
5. Upload the files **inside** the folder into the repository root.
6. Replace matching v1.3 files and commit to `main`.
7. Wait for GitHub Pages to redeploy.
8. Completely close CoastCast and reopen it. If needed, refresh the web version once to update the service-worker cache.

## First test
- Home → choose a target species → scroll to **Bait & Rig Intelligence**.
- Tap **Use this plan**.
- Trips → confirm the bait plan appears in **Go Fishing Mode** and **Smart Gear Planner**.
- Home → Regulations Watch → open official regulations, review them, return, and tap **Mark checked today**.

Existing catches, spots, profile, trips, Scout data and alerts migrate forward.
