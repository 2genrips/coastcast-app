# CoastCast v1.5 — Android / GitHub Pages Update

1. Download `coastcast_v1.5_ocean_iq_safety.zip`.
2. Extract it in Android **My Files**.
3. Open the extracted `coastcast_v1.5` folder.
4. Open your existing CoastCast GitHub repository.
5. Choose **Add file → Upload files** and upload everything inside the folder into the repo root.
6. Replace matching v1.4 files and commit to `main`.
7. Wait for GitHub Pages to redeploy, fully close CoastCast and reopen it.

## First test
- Home → **Ocean IQ**: confirm tide stage, next turn, movement windows and Moon & Light populate.
- With Live Data enabled, source chips should include **NWS alerts — LIVE** when the NWS point-alert request succeeds, even when there are zero active alerts.
- Forecast → **7-Day Tide Planner**: verify several days of high/low events are shown.
- Trips → **Departure Check**: verify hazards, regulations review and gear progress are summarized.

Existing catches, profile, favorites, Scout results, trip plans, alert rules, bait plan and gear state migrate from v1.4.
