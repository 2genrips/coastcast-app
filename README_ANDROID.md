# CoastCast v0.7 — Android / GitHub Pages Update

1. Download `coastcast_v0.7_spot_intelligence.zip`.
2. Extract it with Android My Files.
3. Open your existing CoastCast GitHub repository.
4. Choose **Add file → Upload files**.
5. Upload everything inside the extracted `coastcast_v0.7` folder.
6. Replace the matching v0.6 files and commit to `main`.
7. Wait for GitHub Pages to redeploy.
8. Open the same CoastCast address/app icon.
9. If v0.6 remains cached, close the installed app, open the site in Chrome, refresh once, then reopen CoastCast.

## Test v0.7
- Open **Map**.
- Tap **Scan fishing area**.
- CoastCast will try to load real named public map places around the selected fishing destination.
- Tap **Analyze** on a place to switch CoastCast to its exact coordinates and refresh live Weather + Marine + NOAA data.
- Tap **Save** to keep it as a private waypoint.
- In Bait & Tackle, use **Shop → spot** to route from a shop to the fishing destination.
