# CoastCast v1.6 — Android Update

1. Extract this ZIP on Android.
2. Upload everything inside the `coastcast_v1.6` folder to the root of your existing CoastCast GitHub repository.
3. Replace matching files and commit to `main`.
4. Wait for GitHub Pages to deploy.
5. Fully close CoastCast and reopen it. If v1.5 remains cached, refresh the GitHub Pages site once in Chrome.

## First test
1. Turn on Live Data.
2. Home → Beach Readiness.
3. Forecast → Catch Forecast Timeline → tap the strongest window.
4. Trips → Smart Departure → set your drive time → Recalculate.
5. Try Share trip brief.

Existing v1.5 catches, trips, favorites, alerts, profile, gear checks and regulation-review records migrate automatically.
